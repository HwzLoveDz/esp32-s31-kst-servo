# ESP-IDF and managed-component notices

These license texts accompany the ESP32-S31 application binary and its pinned
build dependencies. Source locations correspond to ESP-IDF commit
`c712a0dde385d659a1470a136251980d31a70bc1` and `dependencies.lock`.
Some dependencies are brought in by the board support package; inclusion in
this notice inventory does not imply a feature is enabled by the application.

The board-generated code has its license alongside the source. The STM32
adapter firmware has a separate license inventory in
[firmware/zt-canable-candlelight/licenses](../firmware/zt-canable-candlelight/licenses/SOURCES.md).
